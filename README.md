# Game Hub

One library for every game installed on your Windows PC.

## Download

**[Download GameHubSetup.exe](https://github.com/Sentral-Hub/game-hub-releases/releases/latest/download/GameHubSetup.exe)** and double-click it. Nothing else is needed: Python comes built in.

It installs just for your Windows account (no administrator rights), adds Game Hub to your Start menu, and appears in Windows Settings → Apps for uninstalling.

Windows may show "Windows protected your PC" the first time, because the installer isn't signed. Click **More info**, then **Run anyway**.

### Running without installing

If you already have Python 3.12 or newer, you can also download `game_hub.py` and `Start Game Hub.bat` into one folder and double-click **Start Game Hub.bat**.

Game Hub updates itself. When a new version is ready, it shows **Update ready** in the sidebar.
