# Game Hub

One library for every game installed on your Windows PC.

## Get started

1. Install Python 3.12 from [python.org](https://www.python.org/downloads/) and tick **Add python.exe to PATH**.
2. Download `game_hub.py` and `Start Game Hub.bat` into the same folder.
3. Double-click **Start Game Hub.bat**.

To install it like a normal app, with Start menu and desktop shortcuts, double-click **Install Game Hub.bat** instead.

Game Hub updates itself. When a new version is ready, it shows **Update ready** in the sidebar.
